## MVP 核心能力

- 自然语言提出民族文化研学问题
- 基于权威音视频资源返回证据化答案
- 定位关键原片片段与时间码
- 生成文化关联、研学路径与学习卡片
- 支持教师备课、学生探究和行前研学等场景
