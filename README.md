# 文化寻脉｜联图云 AI 研学创作功能 MVP

面向高校学生课程展示与课程论文场景，验证“主题输入 → 联图云实时检索 → 素材化大纲 → 证据预览与勾选 → 素材包下载 → 可编辑成果生成 → 本地成果库”的完整闭环。

## 已实现

- 围绕用户主题生成多组站内检索词，调用联图云公开搜索接口后合并去重，并按“主题词、地域、文化形态、偏题词”重新排序。
- 保留资源编号、出版社/来源、年份、平台原始简介、封面和原始详情链接。
- 接口异常时自动回退到 2026-09-13 已核验的联图云快照样本，并在页面明确提示。
- 根据学生最终选择的直接相关资源动态生成六章素材化大纲，每章包含核心观点、两条最强站内证据和论证边界。
- 生成前校验章节证据覆盖率、主题直接相关率、章节观点支撑率和视觉素材可嵌入率，未达门槛不允许生成成果。
- 预览时明确区分“平台原始简介”与“MVP结构化摘要”。
- 一键下载 ZIP 素材包，内含 Markdown 大纲、CSV 引用清单和 JSON 机器可读清单。
- 一键生成并下载可编辑 PPTX：封面图/图片已真正写入文件，每章按“观点＋证据要点＋真实素材图”排版；图片可点击回到对应联图云原始页。
- 课程论文模式可下载 Word 兼容稿。
- 成果与反馈保存在当前浏览器，支持打开和再次下载。
- 模板匹配、候选模板沉淀仍是后台策略，不要求普通用户操作。

## 本轮边界

- 当前 PPT 会嵌入公开封面或图片。视频本体尚未直接写入 PPT：现有公开页面提供 HLS 播放流，但没有面向成果生成的、可授权下载或转码的 MP4 接口；V2 采用“视频封面嵌入＋点击回到联图云播放”。
- 静态 GitHub Pages 无法自行代理跨域图片，本轮测试使用公开图片转发服务读取公开封面。生产版必须替换为联图云自有媒体代理/导出接口，并纳入账号权限、授权范围、审计和水印策略。
- 结构化摘要和章节建议由前端 MVP 规则生成，用于验证产品链路，不冒充已经部署的大模型服务。
- 正式生产版仍需接入机构统一身份认证、授权接口、服务端大模型、审核后台和运营数据看板。

## 验收路径

1. 输入默认主题并点击“开始实时检索”。
2. 查看实时命中总量，打开任一资源的联图云原始详情页。
3. 至少保留 3 项直接相关资源，生成素材化大纲。
4. 下载素材包并检查 ZIP 内的三个结构化文件。
5. 确认四项质量门禁通过后生成 PPT 或课程论文；打开 PPT，确认素材图已经嵌入、正文可编辑、图片点击后能回到原站。
6. 在“我的成果”中再次打开、下载，并提交一条测试反馈。

## 运行

这是无构建步骤的静态网页，使用本地静态服务器或 GitHub Pages 即可运行。页面需要联网加载 React、Babel、JSZip、PptxGenJS，并访问联图云公开接口。
